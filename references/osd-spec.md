# OSD 与档案文案规范

时间戳是这个形式的**信誉来源**。观众不一定看得懂"未时七刻"，但他能看出"这个时间戳很讲究"。反过来，一处不讲究，整条片子就从"记录"变成"段子"。

## 一、三行文字的写法

OSD 由三块组成，全部由 `cctv.py` 烧上去：

| 位置 | 内容 | 例 |
|---|---|---|
| 左上第一行 | 朝代 · 年号年份 + 农历月日 + 干支 | `大明·万历十五年 三月初七 丁亥` |
| 左上第二行 | 时辰刻分（会走字） | `未时七刻 二分` |
| 右上 | CAM 编号 + 机位名 | `CAM 03 / 御膳房·东廊` |
| 左下（可选） | 存档单位水印 | `内务府档案` |

## 二、年号与干支

`cctv.py clock` 内置了常见年号表，直接查得到公元年和干支：

```bash
python3 $SKILL/scripts/cctv.py clock --dynasty 大明 --era 万历 --year 15 --month 3 --day 7 --hour 14 --minute 32
# → 大明·万历十五年 三月初七 丁亥 / 未时七刻 二分
```

| 朝代 | 常用年号（元年公元） |
|---|---|
| 秦/汉 | 建元（前140）、元狩（前122）、建武（25）、永平（58）、建安（196） |
| 唐 | 武德（618）、贞观（627）、开元（713）、天宝（742）、大历（766） |
| 宋 | 太平兴国（976）、庆历（1041）、熙宁（1068）、宣和（1119）、绍兴（1131） |
| 明 | 洪武（1368）、永乐（1403）、宣德（1426）、成化（1465）、嘉靖（1522）、万历（1573）、崇祯（1628） |
| 清 | 顺治（1644）、康熙（1662）、雍正（1723）、乾隆（1736）、嘉庆（1796）、道光（1821）、光绪（1875） |

**选年号的讲究**：

- 选**在位中后期**（如万历十五年、乾隆三十年），朝政松弛，才有闲事可拍。开国初年人人紧张，不适合。
- 别用末代年号（崇祯末年、宣统），观众会联想到亡国，气氛就变沉重了。
- 干支是加分项，不是必需项。查不到就不写，别瞎编。

## 三、时辰换算

一时辰 = 2 小时 = 8 刻；一刻 = 15 分。一昼夜 96 刻。

| 时辰 | 现代时间 | 画面适合 |
|---|---|---|
| 子 | 23:00–01:00 | 最深的夜，偷东西、密谈、打更 |
| 丑 | 01:00–03:00 | 值夜、熬不住打瞌睡 |
| 寅 | 03:00–05:00 | 备膳、开城门前的准备 |
| 卯 | 05:00–07:00 | 上朝、点卯、赶路（迟到高发） |
| 辰 | 07:00–09:00 | 早市、衙门开印 |
| 巳 | 09:00–11:00 | 办公、算账、偷懒 |
| 午 | 11:00–13:00 | 用饭、午睡（偷吃高发） |
| 未 | 13:00–15:00 | 下午犯困（打瞌睡高发） |
| 申 | 15:00–17:00 | 放学、收摊、散值 |
| 酉 | 17:00–19:00 | 关城门、掌灯 |
| 戌 | 19:00–21:00 | 夜宴、掌灯后 |
| 亥 | 21:00–23:00 | 散席、送客、翻墙 |

**一致性铁律**：夜视画面必须配夜里的时辰（子/丑/亥），白天画面必须配白天的时辰（卯–申）。写反了，懂的人一眼出戏。

## 四、宫署名与机构名（要真名）

不要写"厨房""办公室""仓库"——写真实机构名，可信度立刻不同。

| 类别 | 可用名 |
|---|---|
| 内廷 | 御膳房、尚衣局、尚食局、内官监、内务府、造办处、敬事房、钟粹宫、乾清宫、坤宁宫、御花园 |
| 医/礼 | 太医院、御药房、光禄寺、鸿胪寺、钦天监 |
| 禁军/监察 | 锦衣卫、东厂、銮仪卫、五城兵马司、上林苑监 |
| 外朝 | 六部、都察院、大理寺、通政司、翰林院 |
| 地方 | 县衙、府衙、按察司、驿丞署、巡检司、卫所、盐运司 |
| 市井 | 布庄、药铺、当铺、茶楼、酒楼、澡堂、船埠、镖局、马市 |
| 城门 | 午门、正阳门、德胜门、西直门、城门·门禁、城墙·垛口、角楼 |

**机位名写法**：`大地点·小位置`，中间一个间隔号。

- `御膳房·东廊`、`乾清宫·值房`、`县衙·大堂`、`粮仓·仓门`、`城墙·垛口`
- 别写 `御膳房走廊东侧第三个门`——监控标签没人写这么长。

## 五、CAM 编号规则

编号不是随机数，它暗示了"这套系统有多大"：

| 范围 | 含义 | 例 |
|---|---|---|
| 01–09 | 室内小场所（房间、廊道、库房） | `CAM 03` 御膳房·东廊 |
| 10–19 | 门禁与通道（宫门、城门、院门） | `CAM 12` 午门·内侧 |
| 20–29 | 室外大场（广场、校场、街面） | `CAM 21` 集市·布庄 |
| 30+ | 特殊/临时加装（案发后补装） | `CAM 31` 御膳房·后门 |

**同一场景的多条片子，编号必须一致**——这是做系列的地基。做"同一机位 24 小时"，CAM 03 永远是那条走廊。

## 六、档案卡（片尾）

三行，从大到小：

```
内务府档案
卷三一七 · 万历十五年三月初七
御膳房 东廊 · CAM 03
```

| 行 | 内容 | 写法 |
|---|---|---|
| 1 | 存档单位 | 内务府档案 / 锦衣卫北镇抚司 / 刑部档房 / 县衙架阁库 |
| 2 | 卷号 + 日期 | `卷三一七`（汉字数字，别写 317）、`万历十五年三月初七` |
| 3 | 机位 | `御膳房 东廊 · CAM 03` |

**卷号要像真的**：`卷三一七` 比 `第 1 号` 可信十倍。可以用汉字数字，也可以混一点编号感（`甲字库·第七架`）。

## 七、颜色与字体

| 参数 | 用途 |
|---|---|
| `--osd-color white`（默认） | 现代 DVR 的白字，最通用 |
| `--osd-color green` | 老式单色监控，复古感最强 |
| `--osd-color amber` | 老磁带/录像机，暖黄 |
| `--osd-scale 0.85` | 字太大压画面时缩一点 |
| `--font "Songti SC"` | 想要更"旧"的观感（默认自动挑黑体） |

字体由 fontconfig 解析。脚本会自动在系统里挑可用的中文字族，找不到合适的就是豆腐块——所以**不要**手写 `PingFang SC` 之类未必存在的名字，交给 `--font` 留空自动挑。

## 八、时间戳走字

默认 60 倍速：现实 1 秒 = 片中 1 分。一条 20 秒的片子，时间戳走 20 分，看起来"确实过了一段时间"。

- 想要几乎不动（更真实，因为真实监控 20 秒也就走 20 秒）：`--clock-speed 1`
- 想要时间跨得夸张（换场次用）：`--clock-speed 300`
- 想用现代时分秒（年号日期 + `14:32:07`）：`--clock-style modern`——这种混搭反而最像"穿越感"，很多爆款用的就是这个

跨时辰时脚本会自动进位（未时八刻 → 申时一刻），日期跨天也会进位。
