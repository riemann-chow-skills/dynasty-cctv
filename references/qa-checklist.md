# 交付前质检

按顺序过一遍，一项不过就回去修。**前四项是形式，后两项是内容**——形式塌了内容再好也没用。

## 一、看机位（形式的第一根柱子）

- [ ] 整条片子的机位**没有移动过**（没有推、拉、摇、移、变焦）
- [ ] 是高处俯视（俯角 25–50°），不是平视，不是仰视
- [ ] 画面边缘有广角拉伸感，但**没有鱼眼球化**
- [ ] 没有景深虚化（前景后景都清楚，这是监控镜头的特征）
- [ ] 同一场景的多条镜头，机位**完全一致**（不一致就等于换了个摄像头，要换 CAM 编号）

## 二、看画质（形式的第二根柱子）

- [ ] 整体偏灰偏平，没有主光、没有轮廓光、没有逆光光斑
- [ ] 有可见噪点（不是干净的高清素材）
- [ ] 有扫描线或轻微条纹（`--scanlines 4` 默认开）
- [ ] 四角略暗（暗角在，但不明显到抢戏）
- [ ] 画面不"锐"——边缘是软的

> 判断标准：把片子缩小到手机屏幕的 1/4，如果看起来像"从某个系统里导出的"，就对了；如果看起来像"某部电影的一段"，就错了。

## 三、看文字（最容易翻车）

- [ ] 画面里**没有模型画的假字**（匾额、招牌、时间戳）——有就重出首帧，别想着后期盖住
- [ ] 时间戳完整可读，没有被画面亮部吃掉
- [ ] CAM 编号与机位名对得上（`CAM 03` 配 `御膳房·东廊`，不是 `CAM 03` 配 `县衙·大堂`）
- [ ] 中文没有豆腐块（□□□）——有就是字体没找到，加 `--font` 指定
- [ ] 时间戳在走（抽两帧对比，数字应该变了）
- [ ] 红点在闪（不是一直亮，也不是一直灭）
- [ ] 四角没有生成工具的"AI生成"水印残留（没裁到 16:9 就会留着，检查 `--size`）

## 四、看时间与空间的一致性

- [ ] 夜视/夜景画面配的是夜里的时辰（子/丑/亥），白天画面配白天（卯–申）
- [ ] 朝代、年号、服饰三者对得上（明代的片子不能出现辫子）
- [ ] 农历月日与季节感对得上（三月初七不该满地落叶）
- [ ] 同一场景内时间戳**连续递进**，没有倒流
- [ ] 片尾档案卡的日期 = 片头时间戳的日期

## 五、看内容（好不好笑）

- [ ] 每个镜头里都有**一件明确的事**从发生到结束（或到被发现）
- [ ] 全片有**一个**包袱点，不是每镜都在抖机灵
- [ ] 人物表情正常，没有挤眉弄眼、没有看镜头、没有夸张表演
- [ ] 没有旁白、没有解释性字幕
- [ ] 你自己看第二遍还笑得出来（第一遍笑是新鲜，第二遍笑才是真的）

## 六、看声音

- [ ] 有底噪（电流声/粉噪），不是死寂
- [ ] 没有配乐
- [ ] 没有模型自带的环境音里混进的音乐/人声台词（有就 `--audio bed` 覆盖掉）
- [ ] 音量不炸（底噪应该是"贴着耳朵的一层沙"，不是"沙沙响"）

## 七、交付规格

| 项 | 建议 |
|---|---|
| 时长 | 12–25 秒（3–5 镜 × 4–5 秒） |
| 分辨率 | 1280×720 或 960×540（反正要降清，别用 1080P 浪费） |
| 帧率 | 25（默认）或 15（更卡顿、更像老机器） |
| 比例 | 16:9 横屏 / 4:3 复古 / 9:16 竖屏（`--size 1080x1920 --fit crop`） |
| 码率 | CRF 20 默认，想更糊就 26 |
| 封面 | `cctv.py still` 出的静帧，同一套质感但不带噪点闪烁 |

## 八、最后一步

把成片完整看一遍——**不快进、不静音**。

监控视频的魅力在于"你明知道它是假的，但还是想看看接下来会发生什么"。如果连你自己看的时候都在想"这段什么时候结束"，那这条片子就不该发。
